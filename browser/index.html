🎫 Coupon Clipper

Clip every coupon in one tap — on your own account.

🛒 Shop at Fry's, Ralphs, King Soopers, Smith's, Fred Meyer, QFC, Dillons or another Kroger store? There's a Kroger version too — on Android tap install the Kroger clipper (add it in step 2 the same way); on iPhone pick Kroger family in step 1 below. It clips up to ~150 at a time — just tap again for more.

1 Get the Firefox app

This only works in Firefox (not Chrome) on Android.

Install Firefox

Already have it? Skip to step 2. Open these instructions inside Firefox.

2 Add the helper

Tap below, then tap Add to Firefox → Add → Okay.

Add Violentmonkey

This is a trusted, free add-on that lets the clipper run.

3 Add the clipper

Tap below, then tap Confirm installation.

Install the Clipper

You only do steps 1–3 once.

4 Use it

1. In Firefox, go to Safeway coupons & deals and sign in.

2. Tap the red ✂ Clip all coupons button at the bottom-right.

3. Wait for "Done!" — that's it. 🎉

iPhones don't allow add-ons in Firefox, so we use a bookmark instead. It's a few more taps to set up, but then it's one tap to clip.

1 Copy the clipper

Use Safari for the next steps.

2 Make a bookmark

In Safari, open any page, tap the Share icon (□↑) → Add Bookmark → Save.

3 Edit the bookmark

Tap the book icon → Edit → tap the bookmark you just made. Then:

• Change the name to Clip Coupons.
• Delete the web address and paste (the code you copied).
• Tap Done.

4 Use it

1. In Safari, go to Safeway coupons & deals and sign in.

2. Tap the address bar, type Clip, and tap the Clip Coupons bookmark.

3. Wait for "Done!" 🎉

Kroger shows ~150 coupons at a time — when it's done, just tap the bookmark again for the next batch.

Good to know If it says "All caught up!" it means every coupon on your account is already clipped — nothing more to do. New coupons drop weekly, so run it again then.
